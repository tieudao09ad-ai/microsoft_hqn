Hướng dẫn kích hoạt bản quyền:
  • Đối với Windows 11 / Windows 10: Mở Cài đặt (Settings) → Hệ thống (System) → Kích hoạt (Activation) → Thay đổi khóa sản phẩm.
  • Đối với Microsoft Office / Microsoft 365: Truy cập setup.office.com, đăng nhập tài khoản Microsoft và nhập mã key để liên kết bản quyền.
